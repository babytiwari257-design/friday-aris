1. Moment of Inertia (Standard Bodies)

• Uniform Rod (length L, about center): I = ML² / 12 | (about one end): I = ML² / 3
• Solid Cylinder / Disc (radius R): I = MR² / 2
• Solid Sphere (radius R): I = 2MR² / 5 | Hollow Sphere: I = 2MR² / 3

2. Orbital & Escape Velocity

• Orbital Velocity near Earth: v₀ = √(GM / R) ≈ 7.92 km/s
• Escape Velocity: vₑ = √(2GM / R) = √2 · v₀ ≈ 11.2 km/s
• Kepler's Third Law: T² ∝ r³
